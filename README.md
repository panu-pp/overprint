# Overprint

Block-puzzle roguelite prototype with risograph art. Place pieces, clear lines, and chain perks for big multipliers.

- **Play:** open `index.html` in a browser (no build step).
- **Modules:** `riso.js` (rendering), `meta.js` (town meta), `sfx.js` (sound). `*-test.html` are standalone test pages.
- **Balance sim:** `tools/sim.js` (needs `jsdom`): `node tools/sim.js <gameDir> out.json 60 300`
- **Changes:** see [PATCHNOTES.md](PATCHNOTES.md).
